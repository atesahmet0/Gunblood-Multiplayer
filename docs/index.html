How direct play works

The host runs all gameplay and has a latency advantage. The guest sends aim and fire inputs. Public STUN helps discover a direct route; PeerJS’s free public service exchanges connection details so six-digit joining works. Its operators host signaling; neither player maintains a backend. Availability depends on that service.

Gameplay travels directly between browsers, with no TURN relay. Some networks need a relay and cannot connect here. The duel ends when the host leaves. Rematches require both players.

Keep the host tab visible. Share codes only with the friend you want to connect to.
