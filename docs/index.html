How direct play works

The host runs all gameplay and has a latency advantage. The guest sends aim and fire inputs. Public STUN helps discover a direct route; no TURN relay or signaling service is used. The duel ends when the host leaves. Rematches require both players.

Desktop mouse play recommended. Share codes only with the friend you want to connect to.
